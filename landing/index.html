cd AI-Limits-Tracker && npm install

Frequently asked questions

Can I track multiple Claude accounts at once?

Yes — that's the whole point. Add any number of Claude accounts (and ChatGPT and Gemini). Each is fully isolated with its own credentials, token refresh and history, so two Claude accounts show two different numbers side by side.

How do I see my Claude and ChatGPT limits in one place?

Install the mobile app, the self-hosted web panel (which you can add to your phone's home screen), or the Chrome extension. It shows Claude's 5-hour and weekly windows, ChatGPT's Codex limits and Gemini's quotas on a single screen with live reset timers.

Is it safe? Where are my credentials stored?

They never leave your own device or server. On mobile they're in the iOS Keychain / Android Keystore; on the server they're AES-256-GCM encrypted. Requests go straight to Anthropic, OpenAI and Google — there's no third-party backend. The tool only reads your usage, it never generates anything, so it adds no load to your quota.

Is it really free and open source?

Yes. MIT-licensed, free, and the full source is on GitHub. You self-host it yourself and own all your data.

Does it show how many messages or tokens I've used?

No AI subscription exposes a message or token counter, so the app never invents one. It reads the percentage of each rate-limit window the service itself reports, and derives streaks, forecasts and charts from how that percentage changes over time.
