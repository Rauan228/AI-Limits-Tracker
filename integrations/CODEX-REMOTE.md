# Удалённый чат Codex

Веб-панель / PWA трекера → **Агенты → Чат Codex**. С телефона можно создавать
чаты в разрешённых проектах, читать историю Codex, отправлять задачи, видеть
ответы по мере генерации, останавливать работу и отвечать на запросы подтверждения.
После разовой настройки мост запускается при входе в Windows. Дописывать
что-либо в промпты или обновлять хуки не нужно.

Это отдельная функция от watcher: watcher продолжает показывать статусы всех
сессий, а мост управляет чатами через официальный локальный `codex app-server`.
Интерфейс добавлен в веб-панель, отдельное приложение Expo не изменялось.

## 1. Обновить сервер

Из корня репозитория:

```powershell
npm install
npm run build:server
npm run build:web
npm run build:remote
```

Перенесите **server/dist/server.mjs** и всё содержимое **web/dist/** на сервер
поверх существующих сборок. Сохраните существующие `.env`, `APP_SECRET` и базу
данных: миграция выполняется автоматически, новые таблицы не нужны.

При стандартной установке:

```text
server/dist/server.mjs → /opt/ai-limits-tracker/server/dist/server.mjs
web/dist/*            → /opt/ai-limits-tracker/web/dist/
```

Затем на сервере:

```bash
sudo systemctl restart aitracker
```

Сервер слушает `127.0.0.1` за nginx. Если он запущен в контейнере или должен
слушать сетевой интерфейс, явно задайте `HOST=0.0.0.0`. Публичный адрес панели
должен использовать HTTPS. Нынешний nginx-конфиг подходит: WebSocket-прокси
или открытие дополнительного порта не требуются.

## 2. Один раз привязать ноутбук

1. Откройте обновлённую веб-панель → **Агенты → Чат Codex**.
2. Подтвердите пароль панели → **Привязать ноутбук**. Код действует 5 минут
   и используется один раз.
3. На этом ноутбуке из корня проекта запустите:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\integrations\setup-codex-remote.ps1
```

Установщик использует URL из `C:\Users\Public\ai-limits\config.json`, если он
есть, и предложит ввести код. По умолчанию разрешён только этот проект.

Чтобы разрешить также другой проект, запустите установщик из PowerShell так:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\integrations\setup-codex-remote.ps1 -ProjectPaths @(
  'D:\rauanprojects\AI Limits Tracker',
  'D:\rauanprojects\roomfit'
)
```

Установщик копирует собранный мост в
`%LOCALAPPDATA%\AILimits\CodexRemote`, защищает папку ACL текущего пользователя
и SYSTEM, сохраняет отдельный токен привязки и включает скрытый автозапуск
через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\AILimitsCodexRemote`.
Права администратора не нужны. `CODEX_HOME` сохраняется в локальный конфиг;
на этом ноутбуке это `D:\VisualMind\VisualMind\.codex`. Исполняемый файл Codex
автоматически находится в установленном расширении VS Code.

Ноутбук должен быть включён, пользователь должен войти в Windows, а Codex —
оставаться авторизованным. Экран можно заблокировать. Во сне или без интернета
команды не отправляются. Мост восстанавливает соединение сам; скрытый supervisor
перезапускает процесс после сбоя. Запрос после обрыва не повторяется автоматически.

## 3. Чаты из VS Code

Откройте существующий чат → **Продолжить здесь**. Мост попробует возобновить
его через `thread/resume`. Если чат занят другим процессом Codex, завершите
задачу / закройте его там или выберите **Создать копию**: это отдельный чат,
продолжающий сохранённую историю через `thread/fork`.

Подключение к живому stdio-процессу расширения и одновременная синхронизация
одного активного чата между VS Code и телефоном не реализованы. Открытие истории
само по себе не перехватывает сессию. Не запускайте одновременно два агента,
изменяющих одни и те же файлы проекта.

Передаётся последняя часть истории. Полная история остаётся в Codex на ноутбуке.
Поддержаны текстовые сообщения, подтверждения команд и файлов, а также вопросы
`requestUserInput`. Неподдержанные запросы не получают автоматического разрешения.

## Защита

- Токен старого watcher / общий `API_TOKEN` не позволяет управлять ноутбуком.
  Нужна сессия браузера и повторный ввод пароля; доступ действует 15 минут.
- Управляющий cookie — HttpOnly, Secure, SameSite=Strict, привязан к сессии
  браузера. Изменяющие запросы требуют JSON и совпадения Origin с адресом панели.
- Мост сам подключается к серверу по HTTPS. На ноутбуке нет открытого слушающего
  порта, `auth.json` и токены OpenAI на сервер не отправляются.
- Сервер хранит только хеш отдельного токена ноутбука. Данные чата и очередь
  команд находятся в оперативной памяти сервера, не в базе трекера.
- Разрешённые папки задаются локально. Путь проверяется через realpath, включая
  защиту от перехода за границы разрешённого корня через junction/symlink.
- Разрешён ограниченный список операций, произвольные RPC и прямое выполнение
  shell через relay отсутствуют. Новые / возобновлённые задачи используют
  `workspace-write`, `on-request`, reviewer `user`; сеть в sandbox выключена.
  Подтверждения выдаются на одно действие, без «разрешить навсегда».
- Отключившаяся машина не получает накопленные команды на новый процесс.
  После потери ответа проверьте чат перед ручным повтором: операция могла начаться.

Сам сервер является доверенной частью управления: получивший пароль панели
или контроль над сервером сможет поручать агенту действия в выбранных проектах.
Личная VPN может дополнительно ограничить доступ к панели. Разрешение дополнительного
доступа в подтверждении Codex может расширить исходные границы sandbox.

## Отключение и обслуживание

Кнопка **Отключить** отзывает привязку; при следующем успешном опросе мост
останавливается вместе с локальным процессом Codex. Уже выполняющаяся задача
при этом прерывается. Без связи отзыв вступит в силу после восстановления сети.

Отключить автозапуск:

```powershell
Remove-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name AILimitsCodexRemote
```

Для запуска вручную используется
`%LOCALAPPDATA%\AILimits\CodexRemote\start.vbs`. Настройки разрешённых папок —
в `codex-remote.config.json` в той же папке; изменения загружаются при перезапуске.
Повторная привязка после отзыва: запустите установщик с `-PairAgain`.
Не публикуйте конфиг: он содержит токен этого ноутбука.

## Проверки

```powershell
npm test
npm run test:remote
npm run typecheck:all
```

Дополнительная проверка с настоящим Codex и headless Chrome (расходует небольшое
количество лимита, требует локального входа Codex и установленного Chrome):

```powershell
node scripts/check-codex-remote.mjs
```

Она запускает временный сервер только на loopback, использует изолированную
папку Codex, проверяет привязку через браузер, создаёт чат, получает
`REMOTE_CODEX_OK`, проверяет завершение и отзыв привязки. Снимки мобильной и
настольной версии сохраняются в игнорируемой папке `.local-remote/`.
Временная копия локальной авторизации удаляется при завершении проверки.
